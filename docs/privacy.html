Política de privacidad

Job Hunter n8n es una automatización de uso personal. La usa únicamente su autor, con su propia cuenta de Google.

Datos de Google a los que accede

  • Gmail: lee los correos de alertas de empleo de remitentes concretos (por ejemplo, LinkedIn, InfoJobs y Glassdoor). No modifica, envía ni borra correos.
  • Google Sheets: lee y añade filas en la hoja de seguimiento del propio usuario.

Cómo se usan

El texto de esas alertas y los datos públicos de las ofertas se envían a la API de Anthropic (Claude) para extraer y puntuar ofertas. Los resultados se guardan en la hoja del usuario y se notifican a su chat privado de Telegram.

Los datos no se venden ni se comparten con otros terceros, y no se usan para publicidad. El uso de datos obtenidos de las API de Google cumple la Política de Datos del Usuario de los Servicios de las API de Google, incluidos sus requisitos de Uso Limitado.

Almacenamiento y eliminación

La automatización se ejecuta en un equipo del propio usuario. Las credenciales se guardan cifradas allí. El acceso puede retirarse en cualquier momento desde la configuración de seguridad de la cuenta de Google.
